Key Concepts

AES Algorithm Education

What is cryptography?

Cryptography is the study of protecting information by transforming it into unreadable form and restoring it only to authorized parties.

What is symmetric encryption?

Symmetric encryption uses the same secret key for both encryption and decryption, making it efficient for protecting large volumes of data.

Plaintext vs Ciphertext

Plaintext is readable data. Ciphertext is the encrypted output produced after applying the cipher and key.

Secret Key

A secret key controls the transformation process. Protecting the key is essential because possession of the key allows decryption.

What is AES?

AES is the Advanced Encryption Standard, a widely deployed symmetric cipher approved for secure data protection in government and enterprise systems.

AES-128 vs AES-192 vs AES-256

These variants differ in key length: 128, 192, and 256 bits. AES-256 uses 14 rounds, AES-192 uses 12, and AES-128 uses 10 rounds.

AES Encryption Flow

Plaintext ↓ Secret Key ↓ AES Encryption ↓ Ciphertext ↓ AES Decryption ↓ Original Plaintext

SubBytes

Each byte is replaced using a fixed substitution table, introducing nonlinearity into the cipher.

ShiftRows

Rows of the state array are shifted cyclically to spread byte positions across the block.

MixColumns

Columns are mixed using matrix arithmetic to diffuse data across the state and hide patterns.

AddRoundKey

Each round uses a round key derived from the main secret key, ensuring the transformation depends on the key.

Why key security matters

The strength of symmetric encryption depends on the quality and secrecy of the key. Weak passwords, poor entropy, or key leakage can render encryption ineffective. In this project, passwords are never stored or sent to a server.

AES-GCM authenticated encryption

AES-GCM combines confidentiality with authentication. This application uses AES-GCM to protect data and detect tampering with the ciphertext or metadata.
